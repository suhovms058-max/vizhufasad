# Stage 9 Checklist

- [ ] Contract: versioned assessment, strict schemas, allowed-change policy.
- [ ] Persistence: migration, constraints, indexes, two assessments, diagnostic expiry.
- [ ] Local evidence: contours, spatial layout, protected zones, artifacts.
- [ ] VLM: Yandex primary, optional OpenAI fallback, bounded retry, strict validation.
- [ ] Policy: separate scores, configurable thresholds, reasons, overall result.
- [ ] Worker: mandatory gate before `completed`.
- [ ] Retry: one stricter credit-free candidate only.
- [ ] Failure: second rejection hidden and reservation refunded once.
- [ ] Operations: admin-only diagnostics, cleanup and quality metrics.
- [ ] Golden regression: fixtures, tests and generated report.
- [ ] Documentation: env examples, README and Stage 9 runbook.
- [ ] Verification: install, syntax/typecheck, unit, integration, build, smoke, migration, security.
- [ ] Git: focused commits, push and draft PR; no merge to `main`.

# SEO-сеть ВИЖУФАСАД: первая редакция

## Цель

Создать 15 самостоятельных русскоязычных страниц для органического поиска. Каждая страница отвечает на отдельный практический вопрос владельца частного дома и ведёт к одному понятному действию: загрузить фотографию и получить первую концепцию фасада.

Это не набор дорвеев. У каждой страницы свои: поисковое намерение, заголовок, вступление, советы, иллюстрация, список связанных материалов и метаданные.

## Карта спроса

### Коммерческий кластер

1. `/visualizaciya-fasada-po-foto` — «визуализация фасада по фото».
2. `/vizualizaciya-fasada-doma` — «визуализация фасада дома».
3. `/dizajn-fasada-po-foto` — «дизайн фасада дома по фото».
4. `/nejroset-dlya-fasada` — «нейросеть для дизайна фасада».
5. `/fasad-doma-online` — «дизайн фасада дома онлайн».
6. `/fasad-do-i-posle` — «фасад дома до и после».

## Единый стандарт страницы

- Уникальные title, description, H1 и canonical.
- Один H1, четыре содержательных журнальных раздела, FAQ и JSON-LD для хлебных крошек.
- Вступление отвечает на запрос в первом абзаце.
- Собственная журнальная иллюстрация с понятным alt-текстом и заданными размерами. Изображения оптимизированы для web и загружаются лениво за пределами первого экрана.
- Внутренние переходы: главная, каталог стилей, три тематически близких материала и CTA `/app/new`.
- Не обещать рабочий проект, смету, точные расчёты либо строительную консультацию.
- Для инженерно значимых решений предлагать сверить проект и систему отделки с её производителем или профильным специалистом.

## Визуальная система

Новые изображения построены как редакционные сцены частного дома: чистый фасад, понятный материал, спокойная архитектурная перспектива, природный свет. Для сети подготовлены пять оригинальных фотореалистичных WebP-сцен с разными домами и материалами. Они не копируют изображения с главной страницы и оптимизированы для быстрой загрузки.

## Критерии приёмки

- Все 15 маршрутов возвращают 200 в локальной сборке.
- Все новые URL есть в `sitemap.xml`.
- Отсутствуют орфографические ошибки, дубли title/H1/description и битые внутренние ссылки.
- Desktop и mobile-вёрстка не создают горизонтальную прокрутку, изображения не перекрывают текст.
- Публикация — только после просмотра локальных страниц и отдельного разрешения владельца.

# Изображения для журнала фасадных стилей

## Статус изображений

Тридцать изображений в `public/facade-styles/` созданы специально для проекта ВИЖУФАСАД 26 августа 2026 года. Внешние фотографии и материалы случайных сайтов не использованы.

Изображения являются демонстрационными примерами стилевых направлений. Это не фотографии реализованных объектов клиентов и не подтверждение того, что показанная отделка технически применима к конкретному дому.

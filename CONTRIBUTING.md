# Участие в разработке

## Область продукта

ВИЖУФАСАД автоматизирует только создание концептуальных вариантов фасада по фотографии. Не добавляйте ручного дизайнера, оператора, расчёт материалов, строительные чертежи или персональное сопровождение.

По умолчанию должны сохраняться геометрия дома, этажность, окна, двери и кровля. Изменять их можно только после явного выбора пользователя.

## Ветки и pull request

1. Создайте отдельную ветку от актуального `main`.
2. Ограничьте изменение одним этапом.
3. Не смешивайте рефакторинг с продуктовой задачей.
4. Откройте draft PR и перечислите проверки и миграционные действия.
5. Не выполняйте merge в `main` без решения владельца проекта.

## Обязательные проверки

```bash
npm ci
npm run typecheck
npm run build

cd server
npm ci
npm run check
npm test
```

## Секреты и пользовательские данные

Нельзя коммитить `.env`, токены, пароли, фотографии клиентов, заказы, журналы с персональными данными и резервные копии VPS. Перед коммитом проверяйте:

```bash
git status --short
git diff --cached
```
